# Kit Vanilla JS — Exélixi Nexus

Paquete **autocontenido** para HTML/JS sin framework o con bundler.

**Empieza aquí:** [`INTEGRACION.md`](./INTEGRACION.md)

## Contenido

| Ruta                 | Uso                                    |
| -------------------- | -------------------------------------- |
| `nexus-guard.js`     | IIFE para `<script src>` (sin bundler) |
| `core/nexus-core.ts` | Mismo núcleo TS (Vite/Webpack)         |
| `backend/`           | Middleware Express + `.env.example`    |

Copia **toda la carpeta `vanilla/`** al proyecto y sigue `INTEGRACION.md`.
